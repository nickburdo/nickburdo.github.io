# Nick Burdo — Portfolio

Personal portfolio site: a single-page landing (hero, projects, notes, about,
contact), a resume page, and per-project case study pages. Built with Nuxt 4,
Vue 3 and TypeScript, generated as a static site and deployed to GitHub
Pages.
