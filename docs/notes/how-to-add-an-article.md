# Как добавить статью в мини-блог

Одна статья = один `.md`-файл в `app/data/notes/` + одна запись в
реестре `app/data/notes.ts`. Больше ничего трогать не нужно — карточка
на главной и страница статьи рендерятся автоматически из этого реестра.

## 1. Подготовь файл статьи

- Положи файл в `app/data/notes/<slug>.md`.
- **Слаг = имя файла без расширения.** Например, `my-next-article.md` →
  URL `/notes/my-next-article`. Отдельно придумывать слаг не нужно —
  если нужен другой URL, просто назови файл иначе.
- Статья должна начинаться **ровно с одного** заголовка первого уровня
  (`# Заголовок`) — он становится заголовком страницы. Для остальной
  структуры используй `##`/`###`, второй `# `-заголовок в файле
  недопустим.
- Обычный Markdown — заголовки, списки, таблицы, code-блоки
  (` ```lang `), ссылки — всё это уже рендерится корректно.

## 2. Зарегистрируй статью в `app/data/notes.ts`

Добавь импорт файла и новую запись в массив `notes` — как
`PublishedNote` (со слагом и контентом):

```ts
import myNextArticleContent from './notes/my-next-article.md?raw';

// ...внутри массива notes:
{
  slug: 'my-next-article',
  title: 'Заголовок карточки',
  category: 'Категория',
  excerpt: 'Короткое описание для карточки на главной (1-2 предложения).',
  content: myNextArticleContent,
},
```

Поля:
- `slug` — должен буквально совпадать с именем файла без `.md`.
- `title` / `category` / `excerpt` — идут на карточку на главной
  странице; текст самой статьи они не переопределяют.
  **`title` держи идентичным `# H1` в самом `.md`-файле** — ничего не
  сверяет их автоматически, а на карточке и на странице статьи должен
  быть один и тот же заголовок.
- `content` — `?raw`-импорт того самого `.md`-файла.

Всё. После этого шага статья:

- доступна по адресу `/notes/<slug>` (`app/pages/notes/[slug].vue`
  резолвит слаг через `getNoteBySlug`);
- автоматически появляется карточкой на главной странице
  (`HomeNotesSection.vue` рендерит весь массив `notes` через `v-for` —
  никаких дополнительных правок в компоненте не требуется).

## 3. (опционально) Добавь карточку "Coming soon" без статьи

Если хочешь анонсировать будущую тему без готового текста — добавь
запись типа `UpcomingNote` (без слага и контента):

```ts
{
  slug: null,
  category: 'Категория',
  title: 'Рабочее название будущей статьи',
  excerpt: 'О чём будет статья (1-2 предложения).',
  content: null,
},
```

Такая карточка отрендерится с бейджем "Coming soon" и без ссылки —
`HomeNotesSection.vue` определяет это по `slug: null`. Когда напишешь
статью, просто замени эту запись на `PublishedNote` из шага 2 (не
удаляя и не добавляя отдельно).

## 4. Проверь

```bash
npx eslint .
npx nuxi typecheck
npm run generate
```

Всё должно пройти чисто — новый роут `/notes/<slug>` появится среди
пререндеренных.
